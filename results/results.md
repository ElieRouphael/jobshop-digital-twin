# Results

Generated by `python scripts/evaluate.py`. Test seeds 0 to 19 (20 seeds), 60 jobs per run, synthetic workshop (5 machines, 2 AGVs, 4 product families). Same arrivals and breakdowns for every method on a given seed.

Each cell is the mean over the seeds with a 95 % bootstrap confidence interval (percentile, 10,000 resamples). All 480 runs passed the independent checker (`jobshop/checker.py`).

Utilisation = processing time / (machines x makespan). Setup time = total changeover time in the run. Decision time = computing time spent deciding during one run (wall clock; for CP-SAT, 8 solver threads, 3 runs in parallel on the same machine), so it is indicative only; the other columns do not depend on the machine. Training time of the DQN agent is not included.
